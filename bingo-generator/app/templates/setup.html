1. Create the OAuth client

  1. Open Google Cloud console → APIs & Services → Credentials (sign in with the Gmail account that should own the project).
  2. Create credentials → OAuth client ID. Application type must be Web application (not Desktop or Android).
  3. Under Authorised redirect URIs add exactly this value, then click Create:

  4. No trailing slash, no localhost → use the value above verbatim, or Google will answer redirect_uri_mismatch.
